# Quincaillerie Centrale - README fonctionnel complet

Ce document explique le but de l application, les roles, les ecrans, les donnees principales, les calculs et les regles de travail.
Il sert a presenter le projet a un client, un encadreur, un developpeur, un testeur ou un nouvel utilisateur.

## Objectif general
- L application gere les ventes, les clients, les produits, le stock, les fournisseurs, les paiements, les rapports et les utilisateurs.
- Le systeme aide une PME ou une quincaillerie a suivre les operations commerciales courantes.
- Le tableau de bord donne une vue rapide sur le total vendu, l argent deja recu, le cout des produits vendus et le gain.
- Les ventes sont separees des paiements pour montrer clairement les factures non reglees.
- Le stock baisse quand une vente est validee et augmente quand un approvisionnement est enregistre.
- Les fournisseurs gardent les informations de contact et le nombre d approvisionnements.
- Les categories servent a organiser les produits pour faciliter la recherche.
- Les rapports aident a imprimer les situations utiles pour la gestion quotidienne.

## Roles utilisateurs
- Manager: gere toute l application, les utilisateurs, les ventes, les paiements, les produits, les fournisseurs et les rapports.
- Caissier: gere les clients, les ventes, les paiements et les rapports de caisse.
- Magasinier: gere les produits, le stock, les categories, les fournisseurs et les rapports produits.
- Chaque role voit seulement les menus necessaires a son travail.
- Le bouton aide affiche des informations adaptees au role connecte.
- La navigation mobile se fait avec un bouton menu simple.
- Le profil montre le nom, le role et les initiales de l utilisateur.
- La deconnexion vide la session locale et revient a l ecran de connexion.

## Ecrans principaux
- Tableau de bord: resume les indicateurs importants et les activites recentes.
- Clients: cree les fiches clients et affiche leur historique commercial.
- Ventes: cree les factures, choisit les produits, calcule les montants et imprime.
- Paiements: enregistre les encaissements et filtre la caisse par periode.
- Categories: organise les familles de produits et accepte une URL de photo.
- Fournisseurs: gere les contacts fournisseurs sans afficher de prix d achat.
- Produits et stock: affiche les produits, les images, le stock et les approvisionnements.
- Rapports: affiche les factures, les dettes, le livre de caisse, le bilan et l inventaire.

## Calculs financiers
- Total vendu ce mois: total TTC des factures creees pendant le mois.
- Argent deja recu: total des paiements enregistres pendant le mois.
- Cout des produits vendus: quantite vendue multipliee par le prix d achat du produit.
- Gain du mois: ventes hors taxe moins cout des produits vendus.
- La TVA n est pas un gain parce qu elle appartient a la fiscalite.
- Une facture non payee peut deja produire un gain commercial theorique.
- La caisse montre seulement l argent effectivement recu.
- Les dettes clients montrent ce qui reste a payer sur les factures.
