# Documentation du projet

Ce dossier regroupe les documents qui servent a presenter, comprendre et maintenir le projet CRM PME - Quincaillerie Centrale.

## Documents principaux

| Document | Utilite |
| --- | --- |
| `FONCTIONNEMENT_APPLICATION_DETAILLE.md` | Explique le fonctionnement metier de l'application. |
| `DOCUMENTATION_BACKEND.md` | Explique l'API, les routes, la base de donnees et les regles serveur. |
| `DOCUMENTATION_FRONTEND.md` | Explique les pages, composants, formulaires et choix responsive. |
| `AGILE_BACKLOG_ISSUES.md` | Donne une liste d'issues GitHub possibles pour montrer la methode Agile. |
| `diagrammes-sequence/` | Contient les flux importants: auth, approvisionnement, vente, rapports et notifications. |

## Comment utiliser ces documents

Pour une presentation au professeur:

1. Commencer par le README principal du projet.
2. Montrer les modules fonctionnels.
3. Expliquer les calculs du tableau de bord.
4. Ouvrir `AGILE_BACKLOG_ISSUES.md` pour justifier le backlog.
5. Montrer les diagrammes de sequence pour expliquer les flux.
6. Utiliser `DOCUMENTATION_BACKEND.md` et `DOCUMENTATION_FRONTEND.md` pour les questions techniques.

## Methode Agile

Le dossier de documentation aide a montrer que le projet a ete construit par iterations:

- une fonctionnalite est identifiee;
- elle devient une issue ou une tache;
- elle est implementee;
- elle est testee;
- elle est corrigee apres retour;
- elle est poussee sur GitHub.

Cette organisation permet de repondre simplement si on demande pourquoi le projet utilise une approche Agile.
