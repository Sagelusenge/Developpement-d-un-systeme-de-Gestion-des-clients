# Dossier frontend

Ce dossier contient l'interface web React.

Fichiers importants:

- `src/main.jsx`: composants React, navigation, pages et appels API.
- `styles.css`: styles globaux, responsive et apparence des pages.
- `vite.config.js`: configuration Vite.
- `.env.example`: exemple des variables d'environnement du frontend.
- `dist`: dossier genere apres `npm run build`.

Variable principale:

```text
VITE_API_URL=https://developpement-d-un-systeme-de-gestion.onrender.com/api
```

Sur Render, si le root directory est `frontend`, le publish directory peut rester `dist`.
