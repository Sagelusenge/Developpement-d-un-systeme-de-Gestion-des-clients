# Dossier frontend/src

Ce dossier contient le code React de l'interface.

Le fichier `main.jsx` contient:

- la connexion;
- le layout principal;
- le tableau de bord;
- les pages clients, produits, fournisseurs, categories, ventes, paiements, rapports et utilisateurs;
- les composants reutilisables comme les tableaux, modales, boutons et formulaires.

Les appels API utilisent la constante `API_URL`, lue depuis `VITE_API_URL`.
